## D-041 — Framework skills orchestrate / experiment / repro-check / plan-research are referenced-only by design; the Dynamic-Workflow + verify gate is the sanctioned substitute

**Status.** DRAFT — proposed by the agent_system skill-alignment review 2026-06-09;
awaiting human ratification (paste into `DECISIONS.md` to adopt). Low-stakes: it
records existing practice and changes no behavior.

**Date drafted.** 2026-06-09.

**Context.** The agent_system framework symlinks all 24 skills into `.agents/skills/`.
The 2026-06-09 skill-alignment review found four Layer-B skills — `orchestrate`,
`experiment`, `repro-check`, `plan-research` — are *referenced-only*: named in prose
but never invoked as their SKILL.md procedures. The framework `harvest` ledger keeps
re-flagging this as a coverage gap (`orchestrate` → H002/H005/H007; `experiment` →
H002; `repro-check` → H002/H003; `plan-research` is referenced-only by the same
design choice though not itself harvest-flagged). This is NOT decay or a firewall
issue — it is a deliberate substitution that has simply never been recorded.

**Decision.** The consumer's own build vocabulary is the sanctioned substitute for
these four framework skills, and that substitution is intentional-of-record:
- `orchestrate` → the **Dynamic Workflow** primitive (D-037) is the decomposition /
  delegation mechanism.
- `experiment` / `repro-check` → the **`experiments/` ledger + verify gate**
  (tests-green + `code-review` + a real `env -u MOCK_LLM` smoke) is the consumer's
  run-logging-and-reproduction discipline.
- `plan-research` → planning lives in `LOOP_V0.md` + the daily `human/sessions/` notes.
The framework skills remain available; the runtime-safe core and `code-review` /
`slip-ladder` continue to be used. Only these four are formally substituted.

**Alternatives considered.**
1. **Dogfood the four skills on the next experiment run.** Deferred, not rejected —
   worth doing opportunistically, but forcing it now adds ceremony without changing
   outcomes.
2. **Leave it unrecorded.** Rejected: the harvest ledger re-flags it every consumer
   session, generating recurring noise that reads as an open gap when it is settled.
3. **The chosen path: record the substitution as a decision so the divergence is
   intentional-of-record.**

**Rationale.** Same spirit as D-037 / D-025: when the consumer's contract internalizes
a discipline more directly than loading a skill, record the substitution rather than
let a tool-coverage metric imply a deficiency. This stops `harvest` from re-surfacing
a closed question and tells a spawned agent which mechanism is canonical.

**Reversibility.** Trivial — delete this entry; the skills were never removed.
